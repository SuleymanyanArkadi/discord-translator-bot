# Discord-бот-переводчик 🌐

Ставите под сообщением реакцию-флаг (🇷🇺, 🇬🇧, 🇩🇪, 🇦🇲 …) — бот переводит его на язык этой страны и показывает перевод **только вам**. Канал не засоряется: реакция сразу исчезает, а сообщение с кнопкой удаляется через несколько секунд.

- Перевод через **DeepL API Free**, а если DeepL не поддерживает язык, ключ не задан, кончилась квота или произошла ошибка — через **Google Translate** (без ключа).
- 🌐 переводит на ваш язык по умолчанию (задаётся командой `/setlang`).
- Переводятся также `title`/`description` embed'ов (например, сообщений других ботов).
- Кэш переводов, лимит 10 переводов в минуту на пользователя, SQLite для настроек.

Требования: **Node.js 20+** (или Docker).

---

## 1. Создание приложения в Discord Developer Portal

1. Откройте <https://discord.com/developers/applications> и нажмите **New Application**, введите имя.
2. На вкладке **General Information** скопируйте **Application ID** — это `CLIENT_ID`.
3. Перейдите на вкладку **Bot**:
   - нажмите **Reset Token** и скопируйте токен — это `DISCORD_TOKEN` (никому его не показывайте);
   - в разделе **Privileged Gateway Intents** включите **Message Content Intent** и сохраните изменения.

> ⚠️ **Без Message Content Intent бот не увидит текст сообщений** и будет считать их пустыми.

## 2. Приглашение бота на сервер

Боту нужны права:

| Право | Зачем | Бит |
|---|---|---|
| View Channels | видеть каналы | 1024 |
| Send Messages | отправлять сообщение с кнопкой | 2048 |
| Manage Messages | удалять чужие реакции-флаги | 8192 |
| Embed Links | показывать перевод в embed | 16384 |
| Read Message History | отвечать на старые сообщения | 65536 |
| **Итого** | | **93184** |

Ссылка-приглашение (подставьте свой `CLIENT_ID`):

```
https://discord.com/oauth2/authorize?client_id=ВАШ_CLIENT_ID&scope=bot+applications.commands&permissions=93184
```

Если хотите, чтобы бот работал и в ветках (threads), добавьте право Send Messages in Threads: `permissions=274878000128`.

Без права Manage Messages бот всё равно переводит, но не может убрать реакцию (в логе будет предупреждение).

## 3. Бесплатный ключ DeepL API Free

1. Зарегистрируйтесь на <https://www.deepl.com/pro-api> и выберите тариф **DeepL API Free** (500 000 символов в месяц; для регистрации нужна банковская карта, списаний нет).
2. В аккаунте откройте **API Keys** (<https://www.deepl.com/your-account/keys>) и скопируйте ключ. Ключ Free-тарифа заканчивается на `:fx`.
3. Впишите его в `DEEPL_API_KEY`.

Ключ необязателен: без него все переводы идут через Google Translate. Языки, которых нет в DeepL (например, армянский или грузинский), всегда переводятся через Google.

## 4. Установка и запуск

```bash
git clone <repo> discord-translator && cd discord-translator
npm install
cp .env.example .env     # заполните DISCORD_TOKEN, CLIENT_ID, DEEPL_API_KEY
npm run deploy           # регистрация слэш-команд
npm start                # запуск бота
```

Переменные `.env`:

| Переменная | Описание |
|---|---|
| `DISCORD_TOKEN` | токен бота |
| `CLIENT_ID` | Application ID |
| `GUILD_ID` | *необязательно*: ID сервера. Если задан, `npm run deploy` регистрирует команды только на нём, и они появляются сразу. Если пуст — команды регистрируются глобально (появляются в течение часа) |
| `DEEPL_API_KEY` | ключ DeepL API Free |
| `BUTTON_TIMEOUT_SECONDS` | сколько секунд живёт кнопка «Показать перевод» (по умолчанию 7) |

`npm run deploy` нужно запускать только при первом запуске и после изменения команд.

> На Node 22/24 `better-sqlite3` ставится из готовых бинарников. На Node 20 он компилируется при `npm install`, поэтому нужны инструменты сборки: `sudo apt install python3 make g++` (Linux) или Xcode Command Line Tools (macOS). В Docker это уже учтено.

ID сервера: включите в Discord *Настройки → Расширенные → Режим разработчика*, затем ПКМ по серверу → *Копировать ID сервера*.

### Docker

```bash
cp .env.example .env     # заполните
docker compose build
docker compose run --rm bot npm run deploy
docker compose up -d
docker compose logs -f
```

База `data/bot.db` хранится в Docker volume `bot-data` и переживает пересборку контейнера.

### Тесты

```bash
npm test         # юнит-тесты: флаги, нормализация DeepL, фолбэк на Google, LRU-кэш и т.д.
npm run check    # проверка, что все модули импортируются
```

## 5. Как пользоваться

**Перевод сообщения**

1. Поставьте под любым сообщением реакцию-флаг страны, например 🇷🇺 — перевод на русский, 🇺🇸 — на английский, 🇦🇲 — на армянский. Для многоязычных стран берётся основной язык (🇨🇭 → немецкий, 🇧🇪 → нидерландский, 🇨🇦 → английский).
2. Реакция сразу исчезнет, а бот ответит «@вы, перевод готов 🇷🇺» с кнопкой **Показать перевод** (упоминание без уведомления).
3. Нажмите кнопку — перевод появится в сообщении, которое видите только вы, со ссылкой на оригинал. Сообщение с кнопкой удалится.
4. Если не нажать кнопку за 7 секунд, она исчезнет — просто поставьте флаг ещё раз.

**🌐 — перевод на ваш язык.** Задайте язык командой `/setlang`; если язык не задан, используется английский.

**Команды** (ответы видите только вы):

| Команда | Что делает |
|---|---|
| `/setlang language:<язык>` | задать язык по умолчанию (с подсказками вида «Русский (ru)») |
| `/mylang` | показать текущий язык |
| `/translate text:<текст> [to:<язык>]` | перевести произвольный текст; без `to` — на ваш язык |

**Особые случаи**

- Кнопку нажал не тот, кто ставил флаг → «Это не ваш перевод — поставьте флаг сами», кнопка остаётся для автора запроса.
- Бот перезапускался, и кнопка «осиротела» → «Перевод устарел, поставьте флаг ещё раз».
- Сообщение уже на нужном языке → бот всё равно покажет кнопку и отметит это в ответе.
- Сообщения без текста (картинки, стикеры) не переводятся — реакция просто убирается.
- Больше 10 переводов в минуту → реакция убирается без ответа.
- Длинные переводы обрезаются до лимита Discord (4096 символов) с пометкой.

## Структура проекта

```
src/
  index.js            точка входа, клиент Discord, корректное завершение
  deploy-commands.js  регистрация слэш-команд
  config.js           настройки из .env
  flags.js            флаг страны → код языка
  languages.js        список языков, поиск для autocomplete
  db.js               SQLite (data/bot.db, таблица user_settings)
  pending.js          временное хранилище переводов для кнопок
  ratelimit.js        лимит переводов на пользователя
  queue.js            очередь запросов на одно сообщение
  ui.js               embed'ы и кнопки
  events/             обработчики событий Discord
  commands/           /setlang, /mylang, /translate
  translate/          DeepL, Google, LRU-кэш, логика фолбэка
test/                 тесты (node:test)
```
